# Response format

Use this order for a complete assessment. Adapt compactly when a section has nothing meaningful to add.

1. **判定与字数** - identify Task 1/2, question type or visual type, word count, and any input uncertainty.
2. **四项评分** - a compact table with estimated band, evidence from the script, and the principal reason the next band is not yet secure.
3. **综合预估分** - the independent task estimate and a short confidence note. State that it is not an official score.
4. **最影响分数的因素** - rank one to three bottlenecks and name the affected criterion.
5. **审题与内容诊断** - cover misreading, omissions, data selection, position, relevance, development, and support as applicable.
6. **逐句批改** - work in original order. For each sentence needing attention, show `原句`, `建议`, `性质` (错误 / 不自然或不精准 / 可选优化), and `说明`. Group genuinely correct sentences briefly instead of manufacturing alternatives.
7. **Band 8+ 范文** - one complete English response to the exact prompt. Do not provide a consolidated corrected learner draft.
8. **范文拆解** - briefly show the transferable outline, development method, and a small set of useful expressions or structures.
9. **本次返工** - one narrowly scoped rewrite task with an observable target. Do not require a full rewrite unless the whole script is unusable.
10. **档案更新** - confirm concisely what was recorded; do not expose irrelevant filesystem mechanics.

Keep feedback proportionate. Sentence-level coverage can be thorough without repeating the same grammar explanation for every instance; identify the repeated pattern, correct each occurrence, and explain the rule once clearly.
