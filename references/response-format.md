# Response format

Use this order for a complete assessment. Render section headings and explanatory labels in the selected feedback language; keep IELTS criterion names, the learner's writing, corrections, and the model answer in English. Adapt compactly when a section has nothing meaningful to add.

1. **Task identification and word count** - identify Task 1/2, question type or visual type, word count, and any input uncertainty.
2. **Four-criterion scores** - a compact table with the English IELTS criterion names, estimated band, evidence from the script, and the principal reason the next band is not yet secure.
3. **Overall task estimate** - the independent task estimate and a short confidence note. State that it is not an official score.
4. **Highest-impact constraints** - rank one to three bottlenecks and name the affected criterion.
5. **Task and content diagnosis** - cover misreading, omissions, data selection, position, relevance, development, and support as applicable.
6. **Sentence-level corrections** - work in original order. For each sentence needing attention, show localized equivalents of `Original`, `Suggestion`, `Category` (Error / Awkward or imprecise / Optional refinement), and `Explanation`. Keep the original and suggestion in English; explain the category and reason in the selected feedback language. Group genuinely correct sentences briefly instead of manufacturing alternatives.
7. **Band 8+ model answer** - one complete English response to the exact prompt. Do not provide a consolidated corrected learner draft.
8. **Why the model works** - briefly explain, in the selected feedback language, the transferable outline, development method, and a small set of useful English expressions or structures.
9. **Focused revision** - one narrowly scoped rewrite task with an observable target. Do not require a full rewrite unless the whole script is unusable.
10. **Profile update** - confirm concisely what was recorded; do not expose irrelevant filesystem mechanics.

Keep feedback proportionate. Sentence-level coverage can be thorough without repeating the same grammar explanation for every instance; identify the repeated pattern, correct each occurrence, and explain the rule once clearly.
