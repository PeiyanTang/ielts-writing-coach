# Learner profile protocol

Progress tracking is optional. On first use, ask the learner to choose a writable Markdown file location. Do not assume a platform-specific home directory, store personal data inside the installed skill, or expose the profile publicly. Create the parent directory and file only after the learner has chosen the location. Preserve existing entries and edit only this coach's record.

Use these sections:

## Learner context

- Target band and module
- Relevant background supplied by the learner
- Scoring preference
- Feedback-language preference

## Current priorities

Keep no more than five active priorities. Update them from repeated or high-impact evidence rather than one isolated stylistic preference.

## Recurring patterns

Maintain separate Task 1 and Task 2 subsections. For each pattern record its affected criterion, recurrence count or dates, a short authentic example where useful, and whether it is active, improving, or resolved.

## Complete-script history

For each complete submission record the date and a short prompt identifier; task type and word count; four criterion estimates and overall task estimate; highest-impact constraints; assigned revision target; and a compact note on improvement since comparable prior work.

## Revisions

Attach partial rewrites to the originating complete-script entry with date, target, result, and remaining issue. Do not add a new complete-script score.

## Update discipline

- Record evidence, not generic praise.
- Do not infer an IELTS baseline from unrelated examination scores without an official conversion.
- Do not merge Task 1 and Task 2 trends.
- Do not mark a weakness resolved until improvement appears across more than one relevant submission.
- Keep the file concise by consolidating repeated observations instead of appending duplicate advice.
